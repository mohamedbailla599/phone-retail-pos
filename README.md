# Bighrissen Phone

Production-oriented POS and inventory management system for Bighrissen Phone.

## Stack

### Backend
- Django
- Django REST Framework
- PostgreSQL

### Frontend
- React
- TypeScript
- Vite

### Infrastructure
- Docker
- Docker Compose

## Main Domains

- Catalog
- Inventory
- Sales
- Payments
- Customers
- Reservations
- Warranty
- Returns
- Exchanges
- Audit
- Reporting
